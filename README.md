## Project Description
This is a console-based Python application designed to convert monetary amounts between major currencies (**INR, USD, EUR, and GBP**) using fixed exchange rates. The program routes all conversions through INR, validates user inputs for amounts and currency codes, handles potential errors gracefully, and displays the final converted amount rounded to two decimal places.
